## 📖 项目简介
这是一套**完全手写开发**的静态个人网站，面向日常记录、校园随笔、文章投稿展示，无后端服务、无登录鉴权、无API接口，所有文章数据在前端本地加载渲染。
✅ 中考动态倒计时横幅（`zk_countdown.js`），自动区分倒计时、考试进行中、考试结束自动隐藏
✅ Markdown 文章渲染，支持官方发布、用户投稿两套文章分类
✅ 自研 JZR v1.0 加密算法，用户本地加密投稿文本，邮件发送给站长，站长本地解密审核
✅ 移动端自适应布局，侧边栏导航、轮播横幅、文章搜索、标签系统
✅ 用户协议、隐私政策独立页面
✅ 留言、联系表单依托问卷星第三方服务，网站本身不收集用户隐私

网站为非盈利个人项目，没有使用成熟博客框架，全部原生 JS/CSS/HTML 实现。

```
.

├── xie.html                 # 用户协议页面
├── yin.html                 # 隐私政策页面

├── articles.js              # 前端文章数据源，所有文章数据由此读取
```

## 🛠️ 技术栈
- 前端：原生 HTML5 / CSS3 / JavaScript
- Markdown渲染：自研 `markdown-lite.js`，降级支持 CDN marked
- 路由：纯 JS 实现单页面路由，无前端框架
- 部署：Cloudflare Workers（仅托管静态资源，不运行后端逻辑）
- 特色组件：`zk_countdown.js` 中考倒计时组件，多阶段颜色提示
- 加密：自研 JZR v1.0 异或置换加密算法，仅用于投稿文本混淆

> ⚠️ 重要说明：项目**不存在后端API、登录、KV存储**，所有文章数据全部在前端 `articles.js` 维护。

## ✍️ 用户投稿流程
用户打开网站 → 校园动态 → 我要投稿
填写标题、内容、昵称，勾选同意用户协议&隐私政策
前端本地调用加密函数生成以 `JZR1:` 开头加密字符串
用户复制密文，邮件发送到站长邮箱
站长本地使用密钥解密，审核后手动把文章添加进 `articles.js`，重新部署上线
网站所有访客即可看到发布后的文章

用户原始明文不会直接暴露在网络传输，只有管理员持有密钥才能解密阅读投稿内容。

## ⏱️ 中考倒计时组件配置（zk_countdown.js）
修改头部常量即可更换考试名称、科目时间：
```js
var ZK_ENABLED = 1; // 0关闭横幅，1开启
var ZK_NAME = "2029年宁波中考";
var ZK_SCHEDULE = [
  { subject: "语文", start: "2029-06-16 09:00", end: "2029-06-16 11:00" },
  // ...其余科目
];
```
逻辑自动：
- 距离2年以上：绿色
- 1‑2年：黄色
- 1个月‑1年：橙色
- 不足1个月：红色
- 考试进行中：显示当前正在考科目 / 下一场科目
- 全部科目结束：横幅自动隐藏

## 📄 用户协议 & 隐私政策
- `xie.html` 用户协议：规定投稿、留言、版权、免责规则
- `yin.html` 隐私政策：明确本站最小化收集原则，说明问卷星、邮箱、Cloudflare 第三方依赖

两个页面的正文直接修改内部 MARKDOWN_CONTENT 字符串，不需要改动 HTML 结构。

## ⚠️ 已知限制 & 注意事项
1. 纯静态站点，**没有后端、没有数据库**，新增文章需要手动修改 `articles.js` 再重新部署
2. JZR 加密为个人自研玩具加密，不适合高安全生产业务场景，仅用于本站投稿混淆，不要当作高强度加密使用
3. 留言与联系功能完全依赖问卷星，网站本身不存储留言数据
4. 大量图片建议放到 R2/外部CDN，不建议全部塞进 Worker Assets
5. 密钥文件 `key.txt` 禁止上传到公开仓库，投稿解密仅在站长本地完成
